# Token-Control-Platform — Requirements & Evidence Matrix

> **INTERNAL — Betriebsgeheimnis.** · Stand 2026-07-23 (aktualisiert nach R30 + D3/D4)  
> Diese Matrix verhindert „fertig durch Behauptung". `Status` beschreibt den
> verifizierten Worktree: **Built**, **Partial**, **Planned**, **Unknown**.
> Vollständig ist eine Anforderung erst mit dem genannten Target Evidence.

## Statusregeln

- **Built:** Runtimepfad und relevante Tests wurden im aktuellen Code gefunden.
- **Partial:** Bausteine existieren, aber End-to-End-Vertrag/Gate fehlt.
- **Planned:** kein produktiver, verifizierter Zielpfad vorhanden.
- **Unknown:** aktueller Nachweis fehlt; vor Umsetzung in W0 klären.
